## Tips and tricks

**Move window to the specified position**

```vim
:wincmd {arg}
```

Equivalent to `CTRL-W {arg}`.

Positions:
- `CTRL-W K` move current window to the very top
- `CTRL-W J` move current window to the very bottom
- `CTRL-W H` move current window to the very left
- `CTRL-W L` move current window to the very right
